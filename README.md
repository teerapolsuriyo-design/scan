# 🏢 ระบบติดตามและตรวจสอบการเข้าแนะแนวโรงเรียน (School Guidance Visit Tracking System)

> ระบบบันทึกและติดตามการเข้าแนะแนวสะดวกรวดเร็วของทางวิทยาลัย  
> ข้อมูลทั้งหมดบันทึกและดึงแบบ Real-time จาก Google Sheets  
> รองรับการดึงพิกัด GPS อัตโนมัติ เพื่อยืนยันสถานที่แนะแนว  
> เลือกพื้นที่อย่างแม่นยำด้วย Dropdown จังหวัด > อำเภอ > ตำบล ของประเทศไทยแบบอัตโนมัติ (พร้อมระบบ Cache โหลดเร็ว 0ms)

---

## 🚀 วิธีติดตั้งและใช้งาน

### ขั้นตอนที่ 1 — ตั้งค่า Google Sheets & Apps Script

1. สร้าง **Google Sheets** ใหม่ขึ้นมา (หรือใช้ไฟล์ชีตเดิมก็ได้)
2. ไปที่เมนูด้านบนเลือก **Extensions (ส่วนขยาย) → Apps Script**
3. ลบโค้ดเดิมทั้งหมดในไฟล์ `รหัส.gs` หรือ `code.gs` ออก
4. **คัดลอกโค้ดทั้งหมดจากไฟล์ `code.gs` ในโปรเจกต์นี้ไปวางแทนที่**
5. คลิก **Save** (ไอคอนแผ่นดิสก์)
6. คลิกที่ปุ่ม **Deploy (การเปิดใช้) → New deployment (การใช้งานใหม่)**
   - เลือกประเภทการตั้งค่า (ฟันเฟือง) เป็น: **Web app (แอปพลิเคชันเว็บ)**
   - Execute as (เรียกใช้ในฐานะ): **Me (ฉัน)**
   - Who has access (ผู้ที่มีสิทธิ์เข้าถึง): **Anyone (ทุกคน)**
7. กดปุ่ม **Deploy**
8. ทำการอนุมัติสิทธิ์ (Authorize Access) ให้กับสคริปต์เพื่อให้เข้าถึงข้อมูลใน Sheets ได้สำเร็จ
9. คัดลอก **Web App URL** ที่ได้มาเก็บไว้ (เช่น `https://script.google.com/macros/s/xxxx/exec`)

---

### ขั้นตอนที่ 2 — ตั้งค่า API URL บนแอปพลิเคชัน

คุณสามารถตั้งค่า URL ได้ 2 วิธีหลักๆ:

**วิธีที่ 1: ใส่เป็นค่าเริ่มต้นในไฟล์**
1. เปิดไฟล์ `js/api-config.js` ในโปรเจกต์ขึ้นมา
2. แก้ไขที่บรรทัด `const GAS_API_URL = '...'` โดยนำ Web App URL จากขั้นตอนก่อนหน้ามาใส่แทนที่
3. บันทึกไฟล์

**วิธีที่ 2: ตั้งค่าหน้าเว็บแอป (สะดวกที่สุด)**
1. เปิดแอปพลิเคชันขึ้นมาบนเบราว์เซอร์
2. สังเกตที่ปุ่มมุมบนขวา **"⚙️ ตั้งค่า API"**
3. วาง Web App URL ลงในช่อง input แล้วกด **"💾 บันทึกการตั้งค่า"**
4. ระบบจะทำการบันทึกและเชื่อมต่อข้อมูลกับ Google Sheets โดยอัตโนมัติ

---

### ขั้นตอนที่ 3 — บันทึกและทดลองใช้งาน

1. **ดึงข้อมูล (Fetch)**: เมื่อระบบเชื่อมต่อสำเร็จ หน้าจอจะแสดงรายการข้อมูลทั้งหมดจากแท็บแผ่นงาน `GuidanceVisits` ใน Google Sheets (หากเพิ่งสร้างใหม่ จะยังไม่มีแถวข้อมูล ให้สถิติเป็น 0)
2. **การบันทึกรายการเข้าแนะแนวใหม่ (Create)**:
   - กดปุ่ม **"➕ บันทึกข้อมูลแนะแนวใหม่"**
   - กรอกชื่อโรงเรียน, เลือกจังหวัด, อำเภอ, ตำบล ของไทยผ่าน chained dropdown
   - กำหนดวันที่, สถานะ, ชื่อผู้ตรวจสอบ และระบุหมายเหตุหากมี
   - กดปุ่ม **"📍 ดึงตำแหน่ง"** เพื่อระบุตำแหน่งละติจูด ลองจิจูด ปัจจุบันผ่านพิกัด GPS ของอุปกรณ์
   - กดปุ่ม **"💾 บันทึกข้อมูล"** ข้อมูลจะถูกอัปเดตลง Google Sheets ทันที
3. **การค้นหาและกรองข้อมูล**:
   - สามารถระบุชื่อโรงเรียน หรือ ผู้เข้าแนะแนว เพื่อค้นหาอย่างรวดเร็ว
   - เลือกกรองเฉพาะ จังหวัด อำเภอ หรือตำบล หรือตามสถานะการเข้าแนะแนวได้ทันที
4. **การแก้ไขข้อมูล (Edit / Update)**:
   - กดปุ่ม **"✏️ แก้ไข"** บนการ์ดโรงเรียนที่ต้องการอัปเดต
   - แก้ไขข้อมูลในฟิลด์ที่ต้องการ จากนั้นกดบันทึก ข้อมูลใหม่จะทับแถวเดิมในชีต
5. **การลบข้อมูล (Delete)**:
   - กดปุ่ม **"🗑️ ลบ"** บนการ์ดที่ต้องการนำออก เพื่อลบแถวข้อมูลดังกล่าวจากชีตอย่างถาวร
